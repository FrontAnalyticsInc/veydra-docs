# Veydra MCP: Quick Setup

Choose one option. Most teams should start with Option A.

<Info>
Get your API key at [app.veydra.io/account/api-keys](https://app.veydra.io/account/api-keys).
</Info>

## Option A: Hosted URL (fastest)

Use this when your client supports remote MCP URLs directly.

**MCP URL**

```text
https://api.veydra.io/mcp
```

If your client asks for auth, use:

```text
Authorization: Bearer YOUR_VEYDRA_API_KEY
```

### Generic JSON example

```json
{
  "mcpServers": {
    "veydra": {
      "url": "https://api.veydra.io/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_VEYDRA_API_KEY"
      }
    }
  }
}
```

## Option B: npm CLI (best for Claude Code / Gemini CLI)

Use this when your client expects a local command-based MCP server.

### 1) Install

```bash
npm install -g @veydra-io/mcp-server
```

### 2) Login once with OAuth

```bash
veydra-mcp login
```

This opens a Veydra auth page in your browser and stores your CLI session.

### 3) Configure your client

```json
{
  "mcpServers": {
    "veydra": {
      "command": "npx",
      "args": ["@veydra-io/mcp-server"]
    }
  }
}
```

### 4) Optional CLI commands

```bash
veydra-mcp whoami
veydra-mcp logout
```

## Quick Troubleshooting

1. Confirm URL is exactly `https://api.veydra.io/mcp`.
2. If using API keys, confirm key starts with `vk_`.
3. If using npm OAuth, run `veydra-mcp login` again.
4. Restart your AI client after config changes.
